# 户型装修设计使用说明

本工具用于在 2D 户型图中布置家具、调整房间地面和墙体，并在 3D 场景中查看与漫游。尺寸单位为毫米（mm）。

## 启动项目

先安装 Node.js 20.9 或更高版本和 pnpm。在项目目录运行：

```bash
pnpm install
pnpm dev
```

打开终端显示的本地地址即可使用。需要停止时，在终端按 `Ctrl+C`。

首页是“户型图”列表。点击列表卡片进入编辑器；点击“导入户型”可导入 DXF 并直接打开新户型。编辑器左上角的“户型列表”可以返回首页。户型名称可在列表中重命名或删除。

生产环境可运行：

```bash
pnpm build
pnpm start
```

## 2D 平面布置

### 添加和编辑家具

1. 从左侧家具库选择家具或家电。点击会放到画布中央；也可以把它拖到平面图中的位置。触屏设备可点选放置，或按住后拖动。
2. 选中家具后，在画布上拖动可移动它；右侧属性面板可以编辑名称、位置、宽度、深度、角度和颜色。
3. 拖动家具上方的圆形控点可旋转；按住 `Shift` 可自由角度旋转。拖动右下角方块控点可调整尺寸。
4. 开启“贴墙吸附”后，移动家具时会自动贴齐附近墙面。键盘方向键可微调位置：每次 10 mm，按住 `Shift` 时每次 100 mm。

### 工具和视图

- **选择**：选择、移动家具。按 `V` 切换。
- **测量**：点击两个位置，或按住拖动绘制测量线；靠近墙体时会吸附。按住 `Shift` 锁定水平或垂直方向。按 `Esc` 取消当前测量。
- **拆改墙体**：点击非承重墙进行拆改；承重墙会单独标示，不能按非承重墙方式拆改。
- **缩放和平移**：滚轮缩放，拖动画布空白处平移；`+` / `-` 缩放，`F` 适应窗口。
- **比例**：工具栏可切换 `1:60`（与原图同比例）和 `1:100`。
- **图层**：可分别显示或隐藏尺寸、房间名、家具、网格和承重墙；也可以切换贴墙吸附。
- 顶部的家具库和属性按钮可展开或收起对应侧栏。窄屏下侧栏以抽屉形式打开。

### 房间和材料

点击房间可在右侧属性面板修改房间名称和地面材料。面板显示房间面积、家具占地等信息；材料估价按面积计算，并包含 5% 损耗。底部状态栏会显示当前坐标、比例和操作提示。

## 3D 场景

点击顶部的“3D 场景”或按 `T` 切换。3D 与 2D 使用同一方案，家具和房间修改会同步。

- **鸟瞰**：鼠标左键拖动旋转视角，右键拖动平移，滚轮缩放；触屏设备用单指旋转、双指缩放或平移。
- **视角按钮**：使用“斜视”或“俯视”切换相机视角；点击左侧房间列表可飞到对应房间。
- **漫游**：选择漫游后，点击画面开始。桌面端用 `W`、`A`、`S`、`D` 或方向键移动，鼠标控制视线，按住 `Shift` 快走，按 `E` 开关面前的门；按 `Esc` 暂停。触屏设备使用左下角摇杆移动，并拖动画面转向。
- **场景显示**：可切换全高墙或剖切墙，显示或隐藏家具和房间名，开启夜景并调整日照时间。
- **编辑家具**：在 3D 中点击家具可选中；选中后可拖动家具，或在右侧属性面板修改。

漫游模式下，若浏览器未授予鼠标指针锁定，触屏摇杆控制仍可使用；可点击“退出漫游”返回鸟瞰。

## 撤销、保存和导出

- 每个户型的家具、墙体和材料方案会分别保存在当前浏览器的本地存储中。使用相同浏览器和用户配置时，下次打开会恢复各自方案。
- **撤销 / 重做**：点击顶部按钮，或使用 `Ctrl/⌘+Z` 撤销、`Ctrl/⌘+Shift+Z` 或 `Ctrl/⌘+Y` 重做。
- **清空布置**：移除全部家具和家电；墙体、地面材料与测量线保留。操作可撤销。
- **导出图片**：导出当前 2D 平面图或 3D 画面为 PNG。
- **导出方案 JSON**：把当前方案保存为 JSON 文件，方便备份或迁移。
- **导入方案**：选择之前导出的 JSON 文件以恢复方案。
- **方案菜单**：在同一户型内切换方案；可新建空白方案、复制当前方案、重命名或删除方案。每套方案分别保存家具、材料和墙体拆改状态，共享户型几何。
- **重置为默认方案**：重置当前方案的布置和材料；户型几何保留，操作可撤销。

建议在重置方案或更换设备前先导出 JSON 备份。

方案 JSON 只包含当前方案数据，不包含户型几何。导入方案会更新当前方案；DXF 户型导入从首页“导入户型”进入。

### CAD 图纸准备

在首页点击“导入户型”选择 ASCII DXF（`.dxf`）；目前不读取 DWG。导入前可在 CAD 软件另存为 DXF；建议使用毫米单位并清理家具、尺寸标注等无关图层。导入时会显示识别统计和提示，确认后创建独立户型并进入编辑器。

- 房间边界使用闭合多段线，放在名称包含 `ROOM`、`SPACE`、`AREA`、`房间` 或 `户型` 的图层。
- 墙体使用水平或垂直直线/多段线，放在名称包含 `WALL`、`墙`、`隔墙` 或 `承重` 的图层。若没有单独墙体图层，系统会按识别到的房间轮廓生成墙体。
- 窗和门可分别放在图层名包含 `WINDOW` / `窗`、`DOOR` / `门` 的闭合多段线图层。
- 墙厚按图层名推定：普通墙 120 mm，承重墙 200 mm，外墙 240 mm。识别到的斜向墙线会跳过并提示；圆弧墙、块参照、自动提取文字房间名和复杂门窗符号暂不支持。

导入使用 DXF 中的 `$INSUNITS` 单位设置；图纸没有单位标记时按毫米处理。导入后可检查房间面积和 3D 结果，再布置家具并另存为 JSON 方案。

## 语言和快捷键

右上角语言按钮可在中文与 English 之间切换；选择会记在当前浏览器中。

| 按键 | 操作 |
| --- | --- |
| `T` | 切换 2D / 3D |
| `V` / `M` / `X` | 选择 / 测量 / 拆改墙体 |
| `R` / `Shift+R` | 旋转选中家具 90°；`Shift` 反向 |
| 方向键 / `Shift` + 方向键 | 微调家具位置 10 mm / 100 mm |
| `Delete` / `Backspace` | 删除选中家具 |
| `Ctrl/⌘+D` | 复制选中家具 |
| `Ctrl/⌘+Z` | 撤销 |
| `Ctrl/⌘+Shift+Z` 或 `Ctrl/⌘+Y` | 重做 |
| `F` | 适应窗口 |
| `+` / `-` | 放大 / 缩小 |
| `[` / `]` | 展开或收起家具库 / 属性侧栏 |
| `Shift+F` | 全屏 |
| `Esc` | 取消测量或取消选择；漫游时暂停 |
| 漫游：`WASD` / 方向键、`Shift`、`E` | 移动、快走、开关门 |
